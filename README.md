## About Me :

I'm **Prathmesh Chavan**, a software engineer focused on **Artificial Intelligence, Machine Learning, and full-stack development**. I enjoy taking ideas from a rough concept to a working product — designing the backend, building the frontend, integrating AI, and deploying the system.

I learn by building and breaking things. Most of my recent work revolves around **LLM applications, RAG systems, AI agents, ML models, developer tools, and production-ready APIs**.

I'm especially interested in the intersection of **AI + software engineering**: building systems that are useful, scalable, maintainable, and actually solve real problems.

### 🚀 What I'm currently working on
- 🤖 Building AI-powered applications and developer tools
- 🧠 Exploring LLMs, RAG, agents, model inference and applied ML
- ⚙️ Building backend systems, APIs and deployment pipelines
- 🌍 Contributing to and learning from open-source projects

## 🚀 Featured Projects

### 🌿 MANAS — AI Companion
An AI-powered conversational application built with a modern full-stack architecture, with contextual memory, safety-oriented routing, multiple AI providers, and a React + TypeScript frontend backed by FastAPI. [View Repo](https://github.com/prathamc00/Manas-AI)

**Stack:** `Python` `FastAPI` `React` `TypeScript` `Docker` `LLMs`

### 🛡️ DeepGuard
An AI-focused project in the deepfake / media authenticity space, reflecting my interest in computer vision, model-driven detection, and practical AI systems. [View Repo](https://github.com/prathamc00/DeepGuard)

**Stack:** `Python` `Machine Learning` `Deep Learning`

### 🧭 DevPath
A skill-to-project recommendation platform designed to help developers move from learning concepts to actually building projects. The repository uses Python + Flask and includes automated tests and an open-source contribution workflow. [View Repo](https://github.com/prathamc00/DevPath)

**Stack:** `Python` `Flask` `HTML` `CSS`

### 📚 Student Learning Portal
A full-stack learning platform focused on student workflows and educational experiences. [View Repo](https://github.com/prathamc00/Student-Learning-Portal)

### 🧠 AI Coding Agent
An exploration into agentic developer tooling and AI-assisted software engineering. [View Repo](https://github.com/prathamc00/AI-coding-agent)

### 🔎 RAG / LLM Experiments
Hands-on exploration of retrieval-augmented generation, transformer architectures, and LLM internals through projects such as `naive-rag`, `transformers`, `airllm`, and `LLMs-from-scratch`.
